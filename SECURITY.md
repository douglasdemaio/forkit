# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅ |

## Reporting a Vulnerability

Please report vulnerabilities by opening an issue on the [GitHub repository](https://github.com/douglasdemaio/forkit/issues) with the label `security`. For critical issues, contact the maintainers directly via the repository's discussion board. We aim to acknowledge reports within 48 hours.

See [README — Security Audit](README.md#security-audit) for the current audit findings and remediations.
